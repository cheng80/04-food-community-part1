다음 디자인시스템 가이드에 맞게 프리미티브 토큰 생성, 시맨틱 토큰 생성, 컬러팔레트를 렌더할 것.

===

1. 컬러 추출
    - 대상: 화면내 디자인 시안
    - 종류: 브랜드 컬러, 뉴트럴 컬러, 경고 컬러, 성공 컬러, 정보 컬러, 에러 컬러

2. 프리미티브 토큰 생성:
    - 대상: variables 메뉴
    - 명칭:
        - 브랜드 컬러: color-brand-50, 100, ..., 900, 950 (총 11개)
        - 뉴트럴 컬러: color-neutral-50, 100, ..., 900, 950 (총 11개)
        - 경고 컬러: color-추출컬러명-50, 100, ..., 900, 950 (총 11개)
        - 성공 컬러: color-추출컬러명-50, 100, ..., 900, 950 (총 11개)
        - 정보 컬러: color-추출컬러명-50, 100, ..., 900, 950 (총 11개)
        - 에러 컬러: color-추출컬러명-50, 100, ..., 900, 950 (총 11개)
    - 주의사항: 각 팔레트별 뉴트럴색(neutral-50) 대비 3:1, 4.5:1을 만족하는 컬러 선택이 가능하도록 생성

3. 시맨틱 토큰 생성:
    - 대상: variables 메뉴
    - 명칭:
        - 텍스트 컬러: color-text-default, color-text-brand, color-text-on-brand, ...
        - 배경 컬러: color-background-default, color-background-brand, ...
        - 보더 컬러: color-border-default, color-border-error, ...
    - 주의사항: hex 직접 입력 금지. 프리미티브 토큰 variables 참조

4. 팔레트 렌더:
    - 대상: 신규 프레임
    - 방식: 각 컬러별 1행 영역 차지. 각 컬러별 행내 프리미티브 토큰 1개당 정사각형 1개

5. 최종 검토사항
    - [ ] 프리미티브 토큰 명칭이 올바르게 되어있는지 확인
    - [ ] 시맨틱 토큰 명칭이 올바르게 되어있는지 확인
    - [ ] 프리미티브 토큰으로 팔레트가 렌더되었는지 확인
    - [ ] 주의사항이 모두 반영되었는지 확인
